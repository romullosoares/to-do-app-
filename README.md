# ✅ To-Do List — Desafio de Engenharia de Prompt

> Projeto desenvolvido como parte da disciplina **IA no Desenvolvimento de Software**, sob orientação do Prof. Msc. Alexander Gobbato.

---

## 📌 Sobre o Projeto

Este projeto é um **To-Do List funcional** desenvolvido com **HTML e CSS puro**, utilizando **Engenharia de Prompt** como metodologia central de desenvolvimento. O objetivo não foi apenas criar a aplicação, mas aprender a colaborar de forma crítica e consciente com ferramentas de Inteligência Artificial ao longo de todo o ciclo de vida do software.

---

## 🎯 Funcionalidades

- **Campo de entrada** para descrição da tarefa
- **Seletor de prioridade** com três níveis: Alta, Média e Baixa
- **Lista dinâmica** de exibição das tarefas
- **Ação de conclusão** para marcar tarefas como finalizadas
- **Estilização condicional** com cores distintas por nível de prioridade

| Prioridade | Cor de destaque |
|------------|----------------|
| 🔴 Alta    | Vermelho        |
| 🟡 Média   | Amarelo         |
| 🟢 Baixa   | Verde           |

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (variáveis, seletores condicionais, flexbox)

---

## 🧠 Metodologia: Engenharia de Prompt

Todo o desenvolvimento foi guiado por prompts estruturados seguindo os **Três Pilares** da atividade:

### 1. Programação por Pares com IA
A IA atuou como um par de programação — sugerindo abordagens e estruturas — mas a decisão final sobre cada linha de código foi sempre minha.

### 2. IA como Assistente
Utilizei a IA para explicar conceitos de CSS, revisar a lógica de estrutura HTML e identificar possíveis erros semânticos.

### 3. Geração Consciente
Nenhum trecho de código foi aceito sem compreensão plena do que faz e por quê está ali.

---

## 📋 Estrutura dos Prompts Utilizados

Cada prompt seguiu a estrutura abaixo:

```
[Persona]   → Quem a IA deve ser (ex: Especialista em CSS)
[Contexto]  → O que está sendo construído e qual o objetivo
[Tarefa]    → O que precisa ser feito neste momento específico
[Formato]   → Como a resposta deve ser entregue
```

## 🚀 Etapas de Desenvolvimento

| Etapa | Descrição |
|-------|-----------|
| 1️⃣ Planejamento | Discussão com a IA sobre a lógica e os elementos necessários antes de escrever qualquer código |
| 2️⃣ Estrutura | Geração do esqueleto HTML com comentários em cada seção |
| 3️⃣ Implementação | Desenvolvimento da interface e da estilização CSS com prioridades |
| 4️⃣ Revisão | Análise do código final com foco em acessibilidade e organização |
